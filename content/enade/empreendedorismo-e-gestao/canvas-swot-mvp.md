## O que é

- **Business Model Canvas** (Osterwalder e Pigneur): quadro de **nove blocos** que descreve, em uma página, **como uma organização cria, entrega e captura valor**.
- **Análise SWOT** (em português, **FOFA**): diagnóstico estratégico com **Forças** e **Fraquezas** (ambiente **interno**) e **Oportunidades** e **Ameaças** (ambiente **externo**).
- **MVP — Produto Mínimo Viável** (Eric Ries): a versão **mais simples** de um produto capaz de **testar uma hipótese** com clientes reais e gerar aprendizado validado.

## Para que serve

São ferramentas **rápidas** para pensar e validar negócios antes de investir muito: o Canvas organiza as hipóteses, a SWOT situa o negócio no ambiente e o MVP testa essas hipóteses no mundo real.

## Como funciona

### Os nove blocos do Canvas

| Área | Bloco | Pergunta |
|---|---|---|
| **Clientes** | 1. **Segmentos de clientes** | para quem criamos valor? |
| | 3. **Canais** | como chegamos aos clientes? |
| | 4. **Relacionamento com clientes** | que tipo de relação mantemos? |
| **Oferta** | 2. **Proposta de valor** | que problema resolvemos / que necessidade atendemos? |
| **Infraestrutura** | 6. **Recursos principais** | o que é indispensável (pessoas, tecnologia, marca)? |
| | 7. **Atividades-chave** | o que precisamos fazer muito bem? |
| | 8. **Parcerias principais** | quem nos ajuda (fornecedores, aliados)? |
| **Viabilidade financeira** | 5. **Fontes de receita** | como e quanto os clientes pagam? |
| | 9. **Estrutura de custos** | quais os principais custos? |

O Canvas serve para **qualquer setor** (financeiro, educação, logística, big data, impacto social) e é usado para **modelar e validar** a ideia — o problema e a solução — antes ou junto com o plano de negócios. Negócios de impacto também precisam definir seus **segmentos** (muitas vezes, quem paga é diferente de quem é beneficiado).

### Análise SWOT

| | Ajuda | Atrapalha |
|---|---|---|
| **Interno** (controlável) | **S — Forças** | **W — Fraquezas** |
| **Externo** (não controlável) | **O — Oportunidades** | **T — Ameaças** |

**Matriz cruzada (TOWS)** para gerar estratégias: **SO** (usar forças para aproveitar oportunidades), **ST** (usar forças para reduzir ameaças), **WO** (corrigir fraquezas aproveitando oportunidades), **WT** (defensiva: minimizar fraquezas e evitar ameaças).

### MVP e Lean Startup

Ciclo **Construir → Medir → Aprender**:
1. Formule uma **hipótese** ("clínicas pagariam R$ 99/mês para reduzir faltas").
2. Construa o **MVP** mínimo para testá-la: landing page, protótipo clicável, serviço manual por trás de uma interface simples (*concierge*/*Mágico de Oz*).
3. **Meça** com métricas acionáveis (conversão, retenção, disposição a pagar).
4. **Aprenda**: **perseverar** ou **pivotar** (mudar uma hipótese fundamental).

## Características principais

- Canvas é **visual, colaborativo e iterativo** — feito com post-its e revisado a cada aprendizado.
- SWOT separa o que a empresa **controla** do que **não controla**.
- MVP é sobre **aprendizado**, não sobre lançar um produto pela metade.

## Exemplos práticos

:::example Canvas de um app de caronas universitárias
Segmentos: estudantes sem carro e estudantes motoristas. Proposta de valor: carona segura e barata entre campus e bairros. Canais: app e redes sociais da universidade. Relacionamento: comunidade com avaliações. Receita: taxa de 10% por viagem. Recursos: app, base verificada de alunos. Atividades: verificação de usuários, suporte. Parcerias: universidades, seguradora. Custos: desenvolvimento, servidores, marketing.
:::

:::example SWOT de uma software house regional
Forças: equipe experiente em ERP. Fraquezas: dependência de um único cliente grande. Oportunidades: digitalização de pequenas indústrias da região. Ameaças: grandes fornecedores de SaaS com preços agressivos. Estratégia WO: usar a oportunidade regional para diversificar a carteira e reduzir a dependência.
:::

## Vantagens e desvantagens

| Ferramenta | Vantagem | Limitação |
|---|---|---|
| Canvas | visão do negócio em uma página | não detalha finanças e operação |
| SWOT | simples, diagnóstico rápido | subjetiva se não usar dados |
| MVP | valida com baixo custo | MVP mal feito gera conclusões erradas |

## Diferenças entre conceitos semelhantes

- **Canvas × plano de negócios:** um não substitui o outro nem tem ordem obrigatória; o Canvas modela e valida, o plano detalha execução e finanças.
- **MVP × protótipo:** protótipo testa **design/funcionamento**; MVP testa **hipóteses de negócio com clientes reais**.
- **Forças × oportunidades:** internas × externas.

## Pegadinhas

:::trap Nenhum setor "dispensa" o Canvas
Afirmações de que um segmento já nasce validado ou que pode ignorar segmentos de clientes estão erradas.
:::

:::trap MVP não é "versão incompleta para vender"
É o mínimo para **aprender** se a hipótese é verdadeira.
:::

## Questões comentadas

::question 2021-objective-32 Canvas em startups

Correta a **B**: startups de big data (como qualquer outra) usam o Canvas para **modelar e validar a ideia de negócio**, isto é, o problema a ser resolvido. As outras impõem ordens obrigatórias, dispensas ou exclusões que o Canvas não prevê.

## Resumo para memorizar

:::summary
- Canvas (9 blocos): segmentos, **proposta de valor**, canais, relacionamento, receitas, recursos, atividades, parcerias, custos.
- SWOT: **Forças/Fraquezas (interno)** × **Oportunidades/Ameaças (externo)**; estratégias SO, ST, WO, WT.
- MVP: mínimo para **testar hipóteses**; ciclo **construir-medir-aprender**; pivotar ou perseverar.
:::
