# Credential assets

- `Sora-Regular.ttf`, `Sora-SemiBold.ttf`, and `Sora-Bold.ttf` are static instances (weights 400, 600, and 700) of the official Google Fonts Sora variable font: https://github.com/google/fonts/tree/main/ofl/sora. The included `OFL-Sora.txt` applies.
- `signature.png` is the original transparent signature image supplied and authorized by the project owner. The certificate labels the visual issuer as Stacklyst; the image is not a cryptographic signature.
- The Stacklyst logo is drawn from the existing vector outlines in `src/lib/brand-geometry.ts`. Badge outlines are shared by the web component and PDF renderer in `src/lib/credentials/badge-art.ts`.
