Country flags: flag-icons 7.6.0, https://github.com/lipis/flag-icons, MIT license in LICENSE.txt. Only two-letter country/territory SVG files are included. The developer-community flag and the six-stripe rainbow flag are authored SVG geometry; they are theme choices, not country identities.

Brazilian state flags: all 27 state/District SVGs come from https://github.com/akagabi/bandeira-dos-estados-do-brasil at pinned revision `93624a385c870dc11a2ca686a89d3ab73b43538e`. The upstream author credits the Wikipedia state pages. The repository MIT license is preserved in BRAZIL-LICENSE.txt, and exact source URLs/SHA256s are recorded in brazil-sources.json. XML declarations/DOCTYPEs are removed; scripts, event handlers and external references are prohibited. State details are actual vector artwork, not generic replacement symbols.

Pride variants and the communist community flag are authored SVG geometry for the conventional flags described in the catalog. They use no scripts, fonts, external images, tracking or metadata derived from a user's identity. These are explicit optional profile decorations; no flag is selected automatically and no identity is inferred. The choice of one flag neither changes permissions nor unlocks achievements.
